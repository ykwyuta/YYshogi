# うごきがみえる将棋

スマホで遊べる、**こまの動きを覚えていない子どもでも遊べる**将棋です。
駒をタッチすると動けるマスが光り、駒のまわりには動ける方向のマークが付いています。ルールを覚える前から一局指しながら覚えられます。

ブラウザだけで動く静的サイトです。ビルドもサーバーも要りません。Cloudflare（Workers の静的アセット配信）でそのまま公開できます。

- CPU 対戦（よわい／ふつう／つよい、先手・後手・おまかせ）
- ふたりで対戦（1台のスマホを交互に使う）
- ハンデ（駒落ち）：香落ち〜六枚落ち
- **詰将棋 50 問**（1手詰 20・3手詰 20・5手詰 10）。全問に解説つき
- 対局は自動保存。ブラウザを閉じても続きから遊べます
- ホーム画面に追加するとアプリのように全画面で使えます

## 子ども向けのおたすけ機能

| 機能 | 内容 |
| --- | --- |
| うごきマーク | 盤上の駒のまわりに、動ける方向を表示。●＝1マス、▲＝どこまでも、○＝桂馬のジャンプ。 |
| 動けるマスが光る | 自分の駒をタッチすると、行けるマスに緑の●、取れる相手の駒に赤い○。反則になる手（二歩・打ち歩詰め・行き所のない駒・王手放置）は最初から選べません。 |
| あぶないマーク | 行き先が取られそうなマスには「!」。いま取られそうな自分の駒には赤い「!」が点滅。 |
| 相手の駒を見る | 相手の駒をタッチすると、その駒が行けるマスがオレンジで表示されます。 |
| 駒の説明カード | タッチした駒の名前（よみがな）、5×5 の動きの図、やさしい説明を表示。 |
| 成りの確認 | 「なりますか？」で、成った後と成らない場合の動きを図で比べて選べます。成らないと動けなくなる場合は自動で成ります。 |
| 王手のお知らせ | 王手されると画面と王様のマスが赤くなり、「王手！」と表示。 |
| ヒント | CPU がおすすめの手を教えてくれます（光ったマスをタッチするだけ）。 |
| まった | 何手でも戻せます。負けた後でも「まった」で戻ってやり直せます。 |
| 色分け | 自分（先手）は青、相手（後手）は赤の縁取り。相手の駒は下向きですが、文字は読みやすいよう正立のままです。 |
| よみがな | 盤が大きい（タブレット・パソコン）ときは駒によみがなを表示（せっていで切り替え）。 |

「こまの うごき」ボタンでは全部の駒（成り駒を含む）の動きを図で一覧できます。

## 詰将棋

画面上の「つめしょうぎ」ボタン（またはメニュー）から、50 問の問題集を遊べます。

- 自分（先手）は毎回王手をかけて、決められた手数で玉を詰ませます。駒を選ぶと**王手になるマスだけ**が光るので、駒の動きを知らなくても挑戦できます。
- 相手の玉は「残りの駒全部」を持ち駒にして、一番長く逃げる手を指してきます（合駒もします）。
- 手数内に詰まない手を指すと、玉が逃げて「ざんねん」。「まった」で戻ってやり直せます。
- 「ヒント」で次の正解の手が光ります。「こたえを みる」で解説を読んだり、正解手順を盤に並べたりできます。
- 解けると解説（ねらい・駒の守り・まちがえやすい手とその逃げ方）を表示。クリアした問題には ★ が付き、記録は自動保存されます。

### 問題の作り方と検証

問題は `tools/gen-tsume.js` でランダムな局面から候補を作り、詰将棋ソルバー（`js/tsume.js`）で次の条件を満たすものだけを残しました。その中から手筋（捨て駒・両王手・成り・桂馬・頭金など）が偏らないように 50 問を選び、解説を書いています。

- ちょうど N 手で詰み、それより短い手数では詰まない
- 本手順の攻め方の手がどれも唯一（別の正解がない）
- 盤上の攻め駒に無駄がない（どれか 1 枚を取り除くと詰まない）・持ち駒は使い切る

`node test/tsume.test.js` で、全問の手数・正解手順・唯一性と、解説にある「まちがえやすい手」で本当に詰まないこと（玉方の逃げ方まで）を確認しています。

```sh
node tools/gen-tsume.js 3 20 42 > candidates.json   # 3手詰の候補を 20 個（seed 42）
node tools/analyze-tsume.js candidates.json          # 盤面図・手筋・ほかの王手がダメな理由
```

## ルール

一般的な本将棋のルールです。

- 相手の玉を詰ませたら勝ち。指せる手がなくなった側の負け。
- 取った駒は持ち駒として打てる。
- 禁じ手（二歩・打ち歩詰め・行き所のない駒・王手放置）は指せないようになっている。
- 千日手（同一局面 4 回）は引き分け。ただし連続王手の千日手は王手をかけ続けた側の負け。
- 400 手で引き分け。入玉宣言は未対応。
- 駒落ちは、CPU 対戦では CPU 側、ふたりで対戦では後手（あか）の駒を減らします。手番は「じゅんばん」の設定どおり（通常の駒落ちのように上手が必ず先に指すわけではありません）。

## 遊びかた

1. 動かしたい自分の駒をタッチ。
2. 緑の●のマスをタッチすると動く。赤い○は相手の駒を取れるマス。
3. 持ち駒をタッチすると、打てるマスが光る。
4. 迷ったら「ヒント」、間違えたら「まった」。

## Cloudflare で無料公開する

Cloudflare Workers の静的アセット配信を使います。ビルドは不要で、静的ファイルへのリクエストは無料プランでも無料・無制限です。設定はリポジトリに入っている `wrangler.jsonc` / `.assetsignore` / `_headers` だけです。

### 方法 A：GitHub と連携して自動デプロイ（おすすめ）

1. ゲーム本体と `wrangler.jsonc` が入ったブランチを、Cloudflare がビルドする本番ブランチにしておく（このリポジトリの既定ブランチは `master`。ここにマージするか、Cloudflare 側の本番ブランチを変更する）。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にログイン（無料アカウントで OK）→ **Workers & Pages** → **作成（Create）** → **リポジトリをインポート（Import a repository）**。
3. GitHub を連携して `YYshogi` を選ぶ。
4. 設定はそのままで構いません。
   - ビルドコマンド：空欄
   - デプロイコマンド：`npx wrangler deploy`（既定値）
   - ルートディレクトリ：`/`
5. **デプロイ** を押すと `https://yyshogi.<あなたのサブドメイン>.workers.dev` で公開されます。

以降は本番ブランチに push するたびに自動で再デプロイされます。

> **`Could not detect a directory containing static files` で失敗する場合**
> Cloudflare がビルドしたブランチに `wrangler.jsonc` が入っていません（README だけの `master` をビルドしたときなど）。ゲームを含むブランチをマージするか、Worker の **設定 → ビルド → ブランチ管理** で本番ブランチを切り替えてから再デプロイしてください。独自ドメインを使う場合は、Worker の **設定 → ドメインとルート** から追加します。

### 方法 B：手元のパソコンからコマンドで公開

Node.js が入っていれば、リポジトリのルートで次を実行します。

```sh
npx wrangler login    # 初回のみ。ブラウザで Cloudflare にログイン
npx wrangler deploy   # 公開（URL が表示される）
```

公開前に手元で確認したいときは `npx wrangler dev` で http://localhost:8787 に立ち上がります。

### 公開に関係するファイル

| ファイル | 役割 |
| --- | --- |
| `wrangler.jsonc` | Worker 名（`yyshogi`）と、リポジトリのルートを静的サイトとして配信する設定。URL の名前を変えたいときは `name` を書き換える。 |
| `.assetsignore` | 公開しないファイル（README・テスト・設定ファイルなど）。 |
| `_headers` | キャッシュとセキュリティ関連の HTTP ヘッダー。 |

## ファイル構成

```
index.html             画面
css/style.css          見た目（スマホ縦向きを基本に、広い画面では2段組み）
js/rules.js            ルールエンジン（指し手生成・合法手・詰み・千日手・駒落ち）
js/ai.js               CPU 思考（評価関数 + αβ探索 + 静止探索。制限時間で打ち切り）
js/worker.js           CPU の思考を Web Worker で動かす（画面が固まらない）
js/tsume.js            詰将棋ソルバー（正解判定・玉方の応手・ヒント）
js/tsume-data.js       詰将棋 50 問と解説
js/ui.js               描画と操作（おたすけ表示・ヒント・まった・保存）
manifest.webmanifest   ホーム画面に追加したときの設定
icons/                 アイコン
test/                  Node.js で動くテスト（公開はされない）
tools/                 詰将棋の生成・分析ツール（公開はされない）
```

設計は [YYTurnBasedGridGameEngine](https://github.com/ykwyuta/YYTurnBasedGridGameEngine) と同じ構成です。ルールエンジンは DOM に依存しない純粋な関数で、`apply` は常に新しい局面を返します。AI の探索でも同じ指し手生成（`genMoves` / `make` / `unmake`）をそのまま使っています。`index.html` をファイルとして直接開いた場合など Web Worker が使えない環境では、CPU は画面側で考えます。

```js
require('./js/rules.js'); require('./js/ai.js');
let s = Engine.newGame();
const m = AI.think(s.board, s.hands, s.turn, 'normal');
s = Engine.apply(s, m);
console.log(s.kifu); // [ '▲２六歩' ] など
```
